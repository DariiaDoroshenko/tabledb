# Часткова реалізація системи управління табличними базами даних (етап 2)

Десктоп-клієнт на Python + Tkinter, ядро бази даних, unit-тести та (додатково) віддалений сервер.
Варіант: додаткові типи **date** і **dateInvl**, операція **різниця таблиць**.

Потрібно: Python 3.9+ зі стандартним `tkinter`. Сторонніх бібліотек немає.

## Запуск

    python run_gui.py                                  # локальний режим
    python run_gui.py --open база.tdb                  # відкрити файл бази
    python run_server.py --port 8765                   # сервер (теку даних: server_data/)
    python run_gui.py --server http://127.0.0.1:8765   # клієнт, що працює із сервером
    python run_tests.py -v                             # unit-тести

Підключитися до сервера або повернутися до локального режиму можна й у меню «З'єднання».
Сервер за замовчуванням слухає лише 127.0.0.1; автентифікації немає, тому `--host 0.0.0.0` лише в довіреній мережі.

## Структура

    tabledb/            ядро (без залежності від GUI)
      values.py         FieldType, Value і нащадки, ValueFactory — типи та валідація
      model.py          Field, Schema, Row, Table, Database
      operations.py     TableDifference — різниця таблиць (операція варіанта)
      storage.py        DatabaseStorage — збереження/зчитування файлу .tdb (JSON, UTF-8)
      service.py        Backend (інтерфейс для GUI) і LocalBackend
      server.py         HTTP/JSON-сервер;  client.py — RemoteBackend
      errors.py         ієрархія помилок
    gui/                app.py (головне вікно), dialogs.py (діалоги)
    tests/              133 тести (unittest); GUI-тести пропускаються без дисплея
    tools/              make_screenshots.py — автоматичні знімки вікон для звіту
    screenshots/        готові знімки

## Формат типів

| тип | приклад | правило |
|---|---|---|
| integer | `-15` | ціле, 64 біти |
| real | `3.14`, `1e-3` | скінченне число |
| char | `Ж` | рівно один символ |
| string | `текст` | без переведення рядка |
| date | `2026-10-07` | РРРР-ММ-ДД, календарно коректна (високосні роки) |
| dateInvl | `2026-09-01..2026-12-31` | дві дати, початок не пізніше за кінець |
